# HomeForge

A local-first smart home platform that prioritizes privacy, security, and user control.

## Overview

HomeForge is designed to give you complete control over your smart home devices without requiring cloud connectivity. All device control works locally on your network, with optional secure tunnels for remote access.

## Key Features

- **Local-First:** Full functionality without internet connection
- **Privacy-Focused:** Your data stays on your devices
- **Optional Cloud:** Secure end-to-end encrypted tunnels for remote access
- **Open Architecture:** Transparent security design and open protocols
